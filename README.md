# Автоматизированная проверка отчётов DOCX

Веб-сервис и REST API на базе FastAPI для автоматического нормоконтроля текстовых документов `.docx` на соответствие требованиям оформления (ТУСУР / ГОСТ).

## Проверяемые параметры
* **Формат страницы:** строгий контроль формата А4 (210 × 297 мм).
* **Поля страницы:** левое ≥ 30 мм, правое ≥ 10 мм, верхнее и нижнее ≥ 20 мм.
* **Шрифт:** Times New Roman, 14 pt (с учетом проверки стилей по умолчанию).
* **Заголовки:** отсутствие точки в конце заголовков (стиль `Heading`), проверка выравнивания.
* **Титульный лист:** проверка наличия обязательных реквизитов (ТУСУР/Министерство, кафедра, тип работы, город).

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd document-validation-project
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите сервер:
   ```bash
   python main.py
   ```
   Веб-интерфейс будет доступен по адресу: `http://127.0.0.1:8000`

## Запуск тестов
Для проверки корректности работы валидатора выполните:
```bash
pytest
```
